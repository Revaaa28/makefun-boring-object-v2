A one-line review of a silica gel packet — an object so dull its only
printed instruction has to warn people not to eat it.

## Run

```bash
python3 main.py
```

Writes exactly the entry line to `/output/entry.txt` (UTF-8, 1–200 characters).

## Entry

My silica gel packet has spent three years silently absorbing moisture in a shoebox, yet its only label is DO NOT EAT — wildly optimistic about how tempting that job looks.
